# Atividade Prática - Automação de Testes com Playwright (ADS)

Este repositório contém a automação dos 10 primeiros casos de teste do site [Automation Exercise](https://www.automationexercise.com/). O projeto foi desenvolvido como requisito parcial para a disciplina de **Teste e Qualidade de Software**.

## Tecnologias Utilizadas

- Node.js: Ambiente de execução.
- JavaScript: Linguagem de programação.
- Playwright Test: Framework de automação de testes.
- Git e GitHub: Versionamento de código.

## Estrutura do Projeto

- `tests/`: Contém os 10 arquivos de testes automatizados (`.spec.js`).
- `fixtures/`: Contém arquivos auxiliares necessários para os testes (ex: arquivo de upload do TC06).
- `playwright.config.js`: Arquivo de configuração do Playwright (configurado para rodar 1 teste por vez para evitar bloqueios do site).
- `package.json`: Dependências e scripts do projeto.

## Como executar os testes

1. Clone este repositório:
   ```bash
   git clone https://github.com/dnzinn00/atividade-playwright-ads.git
   ```
